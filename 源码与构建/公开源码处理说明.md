# 公开源码处理说明

本包按固定上游来源提供相关实现、固件、构建文件和许可证。为避免把上游开发者的个人工作状态当作必要源码再传播，公开副本移除了Xcode用户状态、一个含绝对用户路径的自动工作区、OpenCore非必要的预编译GDB调试DLL与SDK截图文档；实现源码、头文件、库和各许可保留。

少量上游文档/旧补丁头中的用户目录改成`/Users/USER`。这些处理不修改驱动实现，不影响本文附带的源码补丁目标。详细路径清单见[公开源码裁剪记录](../校验/公开源码裁剪记录.json)。上游源码归档SHA描述下载原件，不是处理后的目录散列；公开目录以全局逐文件清单验证。

固定官方构建中编译器保留的`/Users/runner/work/...`是公开CI通用构建路径，不是机器账户；保留这些二进制字节用于准确验证来源。项目版权署名、协议GUID及源码中的公开测试常量原样保留。没有保留本机或群EFI的真实身份、网络、账户或密钥。
