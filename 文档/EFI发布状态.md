# 完整 EFI 发布状态与依赖来源缺口

**本次先公开文档、参考配置、可追溯驱动和源码；完整可启动EFI暂缓发布。** 以下审查只读归档，没有挂载或修改真实ESP，也没有替换原机驱动。

## 基线与不能直接上传的内容

已核对11月5日MacPro7,1事务写后config，SHA-256为`79665d052ccb1237dba6c4b5440046927aa68eaadadb97876d26266c99a7335d`，完整归档356个卷文件/222个EFI文件；20:20:42身份加载验收通过。原始归档含个人身份、旧config副本、启动日志、系统索引/废纸篓和其他系统引导，不公开原包。

其中`EFI/BOOT/BOOTX64.EFI`属于既有Ubuntu链，不能直接复制当作OpenCore后备入口。未来完整包应使用与OpenCore.efi匹配构建的BOOTx64，并保留读者原有多系统入口。

| 原机VoodooI2C/HID/Input及插件 | 官方5c0c99c/d897813、子模块源码、ArrowLake personality增量已公开；旧产物有差异 | 实际旧构建/补丁记录不足，不能用相同版本号冒充对应源码；完整EFI继续等待 |
| USBToolBox / UTBDefault | 固定1.2.0/a22ea1e来源与原创NHI排除字段已记录 | 固定快照未见明确再分发许可文件；不分发源码/整包，保留官方链接与原创字段差异 |
| AppleALC / BrightnessKeys | 与固定官方输入相同的二进制、源码和许可证已记录 | 随公开参考资料提供；扬声器/背光结论仍限定原机 |

| AirportBZ | 固定0ccab162源码/SDK、构建入口和历史产物SHA已公开 | 已联网但仍抖动；本次不把离线入口说成新机复现成功 |
| IntelBluetooth0037 / 固件 | 固定a414375、合并补丁、精确0291与Intel固件许可已公开 | 固件标记出现但功能失败，实验材料明确单列 |
| OpenCore / UEFI / 救援工具 | OpenCorePkg6d8490d固定源码/工具；原机含NullMothSafe工具 | 整包仍须逐文件核对实际构建和许可，不能混用Ubuntu后备入口；本次只发ocvalidate和模板 |
| VirtualSMC、NVMeFix、AMFIPass、YogaSMC等其余原机项 | 能列出原归档文件存在，不足以仅凭版本确认对应来源 | 原机完整基础栈未全做来源闭合，不补造通过结论、不随首版EFI分发 |
| ACPI / DSDT | 三张相关SSDT已附DSL/AML并有历史复编记录 | 固件DSDT、其他原机表及机器绑定信息不作为通用表公开；完整包须独立审查 |
| OpenCanopy / 主题图片 | 有原机使用与归档记录 | 主题图片来源/许可及所有资源尚未逐项闭合，本次不打包 |
| NVIDIA | NullMoth2.6.6官方获取入口及历史校验记录 | 系统侧kext/GPUBundles/AuxKC不是EFI；不重分发安装包或macOS框架 |

## 后续整包的发布条件

每个活动依赖都能说明实际二进制、对应源码/补丁、固定获取位置和分发条件；清理所有个人身份及旧副本；正确配齐OpenCore启动文件；检查ACPI/驱动/工具引用、依赖与版本；通过配套ocvalidate、逐文件清单和重新解压检查。默认要求读者自行生成独立身份。

若必须换用另一个官方构建，应另列为待硬件验证的新组合，不称为原机已验收整包。本次整理不为发布去改动正在使用的系统；没有来源闭合或新硬件证据时，保持暂缓状态。
