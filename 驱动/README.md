# 驱动文件的证据范围

- `部分通过`：源机器实际安装的IntelMausi本地57A1补丁与AirportBZ本机构建。前者仅接管，后者联网存在抖动，均不能称完整稳定通过。
- `依赖`：已与固定官方构建逐二进制核对一致的AppleALC、BrightnessKeys；AppleALC模块加载不等于声音可用。
- `官方参考-未替换验收`：固定官方Lilu、VoodooI2C/VoodooI2CHID及独立VoodooInput参考构建。它们不是源机器通过功能验收时的相同二进制，不能拿本机成功替它们背书。I2C官方包保持原样；本机ArrowLake personality另以JSON和最终Info参考提供，需在离线副本合并。

发布核对发现：本机历史Lilu/Voodoo输入栈与本次下载的固定官方包不一致。现有证据不能将差异归为恶意修改、工具链差异或某个已知补丁，也没有完整历史构建来源。为让公开材料的源码来源明确，这些历史二进制仅在原工作区保留，没有收入ZIP；发布版保留[历史散列](../证据摘要/本机历史驱动散列.json)、实际已验收链路及最小plist/SSDT增量，另附准确固定来源的官方参考包。

官方VoodooI2C包的GPIO/Services来自其固定提交/子模块；其中VoodooInput子包采用独立固定d897813的RELEASE构建。它是可追溯的参考组合，尚未作为这台机器的替换组合做硬件验收。不要为了本文替换源机器已保留的依赖；当前触控板存在跳动，不以参考替换版冒充修复。蓝牙实验的历史依赖解析针对本机原有Lilu；更换Lilu后需重新检查，不能套用旧依赖校验。

[主教程](../主教程.md)、[验收表](../验收状态表.md)描述的是本机历史修复结果；[发布元数据](../校验/驱动元数据.json)与SHA清单描述本包实际文件，两者明确分开。声卡扬声器通过材料在[音频案例](../修复案例/音频-内置扬声器已通过/README.md)，蓝牙控制器失败材料在[实验目录](../实验)。
